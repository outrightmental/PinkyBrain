# Purpose

PinkyBrain exists to keep itself moving with minimal human attention.

The project should use GitHub Actions as its scheduler and runtime, and GitHub Copilot cloud agent as its coding agent. Every hourly cycle should produce at most one small, durable, reviewable change through a pull request.

The repository should optimize for:

- low-maintenance automation,
- public transparency,
- clear documentation,
- small safe increments,
- and a setup that can be left alone for long stretches.
